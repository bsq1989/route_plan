# 圆形目标规划适配与十组仿真回归

当前默认目标为直径 0.10 米、半径 0.05 米的圆形实体，目标坐标表示圆心。车辆配置同时采用已确认的消除区尺寸：横向宽 0.35 米、向前深 0.24 米。车身仍为 0.50 × 0.60 米，每侧安全外扩 0.10 米。

本次接续仿真提交 `1775cb4`，复用已实现的圆与矩形连续接触判定，完成规划侧接近动作、回归入口和几何记录的补充。历史 v0.2.0 的点模型轨迹与统计保留原样，不作为圆模型验收结果。

## 碰撞与消除规则

圆与安全矩形接触或相切即碰撞；圆与消除区接触或相切即消除，不要求圆心或整个圆进入。消除在前进和旋转时均有效，同一目标同时接触两者时碰撞优先。

目标半径与车辆安全外扩是独立参数，不把半径重复加进 `body_margin`。设局部圆心为 `(u,v)`，矩形边界为 `[xmin,xmax] × [ymin,ymax]`，则接触条件为：

\[
d_x=\max(x_{min}-u,0,u-x_{max}),\qquad
d_y=\max(y_{min}-v,0,v-y_{max})
\]

\[
\sqrt{d_x^2+d_y^2}\le r+\varepsilon
\]

圆心可接触区域对应矩形的直边与圆角偏置，不能用扩大长宽后的尖角矩形替代。动作全过程仍调用 `Scene` 的解析接触检查；规划器不自行用圆心点判定或显示帧采样替代碰撞规则。

## 规划侧适配

已有基础适配在接近位姿中计入半径：设消除区局部前后边界为 `C.xmin、C.xmax`，安全矩形前边界为 `Bsafe.xmax`，目标半径为 `r`，则前向采样范围参考：

\[
d_{near}=\max(C.x_{min}-r,B_{safe}.x_{max}+r)+0.015
\]

\[
d_{far}=C.x_{max}+r-\min(0.015,depth(C)/10)
\]

正常范围下采样 `dfar` 与 `(dnear+dfar)/2`。这允许圆心位于消除区前方、由圆边缘完成接触，同时保持与安全轮廓的间距。候选是否可行仍由完整动作试算决定。

本次补充原地消除候选。当目标在消除器的旋转可接触范围内时，除常规朝向采样外，还尝试对准消除区矩形顶点的方向：

\[
\theta_{pickup}=\operatorname{atan2}(t_y-y,t_x-x)
-\operatorname{atan2}(c_y,c_x)
\]

`c` 为消除区局部顶点。仅当该朝向下圆与消除区的精确接触检查成立，才加入同位置转向候选；随后继续检查整个转向中的消除与碰撞。这样可利用圆边缘及圆角接触完成零平移消除，不必为了让圆心进入矩形而额外移动。

长度优化的距离估计沿用圆形接触范围：

\[
R_{reach}=\max_{c\in\operatorname{corners}(C)}\|c\|+r
\]

一步前瞻及区域 MST 下界均使用 `Rreach`；OMPL 节点与运动边沿用带物理半径的 `Scene` 检查。可行性搜索、局部顺序优化和最终回放共用同一几何模型。

## 记录与回归入口

完整记录保留 `target_diameter`。无目标尺寸字段的历史归档按原点模型，即直径 0，恢复；新圆模型的状态与配置若直径冲突则拒绝回放。

本次新增批量结果中的 `geometry`，显式保存目标形状、直径、车身与消除区尺寸，逐例也记录目标直径。新增 `--seed-list` 和 `--random-only`，可精确复现所选十个种子，不额外加入两个固定预设。

从仓库根目录执行：

```bash
uv run --project planner --locked route-plan compare \
  --seed-list 41,57,28,38,49,70,1,97,85,54 --random-only --timeout 3 \
  --output sim/output/circle-regression-10

uv run --project planner --locked route-plan replay \
  sim/output/circle-regression-10/B-random-54.json --show
```

种子沿用此前随机展示的十组；使用当前圆模型重新生成场景，拒绝目标圆重叠及初始碰撞，因此不保证与历史点模型坐标逐点相同。A 为当前圆模型的可行性方法，B 为同一初解上的长度优化方法，两组使用相同场景和几何参数。

## 回归结果

2026-11-08 本机结果：两种方法均为 **10/10 场景全部消除、无碰撞**，每场 40 个直径 10 cm 的圆。每份计划还从保存的输入重建后，以 0.013 秒和 0.7 秒步长额外回放，检查剩余数、全部目标 ID、直径及失败状态。

| 种子 | A 路程 | B 路程 | B 缩短 |
| --- | --- | --- | --- |
| 41 | 45.57 米 | 45.29 米 | 0.6% |
| 57 | 51.00 米 | 47.06 米 | 7.7% |
| 28 | 65.43 米 | 65.43 米 | 0.0% |
| 38 | 40.23 米 | 37.91 米 | 5.8% |
| 49 | 46.00 米 | 44.53 米 | 3.2% |
| 70 | 48.10 米 | 47.72 米 | 0.8% |
| 1 | 48.36 米 | 48.36 米 | 0.0% |
| 97 | 45.34 米 | 45.34 米 | 0.0% |
| 85 | 40.03 米 | 40.03 米 | 0.0% |
| 54 | 48.04 米 | 43.30 米 | 9.9% |

A 累计 478.11 米，B 累计 464.98 米，减少 2.7%；6 组更短、4 组不变、0 组变长。搜索预算仍为 3 秒，最终回放可增加墙钟耗时。圆形接触及消除器尺寸均已变化，不将该降幅与旧点模型的 14.5% 直接作同条件比较。

66 项仿真测试、29 项规划器测试通过，包含圆边缘接触、圆角接触的原地消除、自定义直径、尖角包围盒误判防护、几何记录重建和精确种子选择。
