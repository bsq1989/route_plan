# 第一阶段静态规划 baseline

当前已实现静态完整准确观测下的首个可运行 baseline。所有目标在启动时已知且位置准确，执行期间仅因消除而减少。首先要求全部清除且不违反运动、碰撞与地图边界规则；如果进一步优化，以总行驶路径最短为目标，当前版本尚未做最短路径优化。

## 实现范围

- 独立 `planner/` Python 包，提供可替换的任务规划与运动规划接口。
- 带回溯的任务搜索，联合选择消除顺序、接近方向和中间位姿。
- 简单转向与前进连接器，支持先到中间位置对准，再直线消除。
- OMPL RRT 绕行后端，以仿真器验证每条运动边，最终接近段更新消除集合。
- `Scene.clone()` 独立试算，完整计划经逐步回放验证才报告成功。
- 自动 IR-SIM 窗口、无窗口动画、截图、完整运行记录及独立重放入口。

任务搜索与运动连接器可分别替换。当前选择用于建立工程与验证基线，后续可加入其他可行性搜索或最短路径方法，共用场景与验收体系。

## 固定回归与批量验证

固定场景保存在 [`planner/tests/fixtures/static_cases.json`](../planner/tests/fixtures/static_cases.json)。每个场景包含冻结输入、配置、搜索预算和已验证的完整可行轨迹。

| 场景 | 目的 |
| --- | --- |
| 空目标 | 无需运动，直接完成 |
| 前方、侧方、后方单点 | 正确选择接近位姿；后方目标先原地转向 |
| 同一直线的多个点 | 一次动作消除多个目标 |
| 直接接近受阻、密集点群 | 换方向或先处理其他目标 |
| 角落目标留到最后 | 验证任务搜索的真实分支回溯，车辆不倒退 |
| 靠近角落的单点 | 提前对准，再沿消除器方向接近 |

另有实际调用 OMPL 的绕行测试：直接行驶会触碰旁侧目标，RRT 找到安全中间路线，完成末端接近后再清除剩余点。所有动作从原始初态完整回放，不只检查终点。

2026-11-08 使用本机 Conda `route-plan` 环境执行：

| 验证项 | 结果 |
| --- | --- |
| 仿真配置、控制、几何与界面测试 | 49 项通过 |
| 规划器测试 | 12 项通过，含 9 个冻结场景的子用例 |
| 默认前方点群 | 10/10 清除 |
| 默认四周包围 | 32/32 清除 |
| 随机场景，种子 0–99 | 100/100 场景通过，每场 40/40 清除 |
| 批量任务总数 | 102/102 通过，逐步回放无碰撞 |

批量搜索预算每场 3 秒，最大展开状态数 2000、最大连接试算数 30000。完整 options、环境版本与逐例摘要保存在 [`baseline-v1.json`](../planner/benchmarks/baseline-v1.json)。本次耗时包含独立回放；耗时数值随机器负载变化，不作为固定性能保证。

随机种子 89 暴露过靠近角落时末端转向空间不足的问题。补充“先在中间位置对准、再直线接近”后，整批重新验证通过。该坐标已进入冻结的 `corner_staging` 回归场景。

## 演示与复现

安装及全部命令见 [`planner/README.md`](../planner/README.md)。在仓库根目录激活环境后：

```bash
conda activate route-plan
route-plan solve --scenario random --seed 7 --show
route-plan solve --scenario random --seed 28 --show
route-plan solve --scenario random --seed 42 --show
```

同一批演示生成的 GIF、PNG 与逐例 JSON 在 `sim/output/baseline/`。GIF 为加速回放，完整 JSON 内保存了独立重放所需的场景、车辆参数与目标位姿序列。`replay` 直接检查这些动作，不重新搜索。

## 能力边界与后续

有限候选方向、访问状态量化、有限绕行和搜索预算可能漏解。`not_found` 或 `budget_exhausted` 只表示本次没有找到完整方案，不证明场景无解。任意布局也可能因车辆尺寸、狭窄消除器或地图边界而无法全部清除。

当前 OMPL 绕行部分保守避开所有未消除点，最后接近段允许消除；尚未实现任意绕行过程中删除目标的扩展状态采样树。当前搜索器可以通过直接动作及连续子任务处理途中消除，但不具有全局完备性或最优性保证。

后续仍先完善静态场景覆盖与多种方法对比，不提前加入新目标、漏检或观测修正。第一阶段稳定后再按既定顺序推进车头方向加点和随机加点。
