# 定向接近与分区拾取仿真需求

在现有二维仿真里建一组可重复的场景，用来验证「原地发现 → 按目标连线选方向 → 朝选定方向渐近 → 扇形圆环分批拾取 → 停车后原地再看」。第一版场景用静态物品，逐步暴露观测结果。上层负责选方向和分批，仿真负责提供观测、执行动作和验证几何约束。

## 场地和三个区域

以 `sim/config/robot.yaml` 为车辆参数来源。默认车长 0.702 m、车宽 0.610 m，四周外扩 0.050 m。前置消除矩形长 0.090 m、宽 0.190 m，近边距车头 0.183 m。物品使用直径 0.10 m 的圆。先用一个 2.8 × 4.2 m 的场地，可换成自定义矩形或现有多边形 fence 场景。

坐标统一使用 `map`，长度为米，接口 yaw 为弧度。当前仿真按车身中心作为 `base_link` 和旋转中心。两个扇形的展开角均为总角度，中心线沿车头。区域判断以物品圆心为准，避碰使用物品的完整半径。

| 区域 | 配置 | 判定 |
| --- | --- | --- |
| 发现扇区 | 视距半径 `view_range_m`、展开角 `view_angle_deg` | 圆心距当前 `base_link` 不超过视距，且相对车头的方位角绝对值不超过半个展开角。原地换朝向后重新取帧，可模拟遮挡。 |
| 清理扇形圆环 | 短半径 `pickup_inner_radius_m`、长半径 `pickup_outer_radius_m`、展开角 `pickup_angle_deg` | 圆心距离位于短、长半径之间，且方位落在角度内，包含径向和角度边界。用于渐近停稳后筛选本轮的目标。 |
| `auto_fence` | `auto_fence_radius_m`，默认 1.4 m | 以本次局部规划起点的实测 `base_link` 为固定圆心，限制执行该计划期间车中心的最大偏离。 |

发现扇区和清理圆环随车辆位姿更新。`auto_fence` 的圆心在单次拾取计划期间固定。近距精测的距离阈值暂按 **1.4 m**，与 `auto_fence` 是独立参数。初始演示可以用发现扇区 **3.0 m / 90°**，清理圆环 **0.75–1.4 m / 60°**。这些是仿真起始值，视距、展开角和两条圆环半径都应能配置。

## 场景执行流程

1. **停稳后原地发现。** 上层可请求当前朝向取帧，或给出目标 yaw，原地转向停稳后再取帧。把已观测、未拾取物品存到上层列表，动态画出当前车位到这些物品的连线。每次转向检查完整扫掠、物品和场地边界。
2. **上层选覆盖最多目标的朝向。** 候选 yaw 可用目标连线及能落入同一扇区的两条连线之间的中间方向，按最短角差计算跨 ±180° 的情况。按清理圆环的展开角统计能覆盖的连线数，平票时优先选预计前进距离短、再选转角小的朝向。仿真执行上层选出的 yaw，并记录预计覆盖的目标。第一版用可替换的示例策略演示这条规则。
3. **朝选定方向渐近。** 上层选择该组里最近的目标作为本次渐近的参考，固定参考 ID，根据停稳后的观测更新坐标并计算下一段直行。仿真执行前检查每段扫掠并反馈实测位姿和受阻原因。目标偏离中心线时，设其车体系坐标为 `(u, v)`，前进 `s` 后的距离是 `hypot(u-s, v)`。首版将短半径到短半径加容差作为停车区间，容差可配置。已在区间时直接重测。若直行无法进入区间、下一段不安全或剩余位移落在底盘死区，返回原因，供上层换朝向或从当前位姿判断可拾取批次。
4. **停稳重测并执行局部计划。** 用实测位姿重算清理圆环。将圆环内且获得精测坐标的目标 ID 和坐标交给 `plan(method="stops", mode="auto_fence")`。沿返回的 `goals` 执行，在 `pickup_stops` 指定位置显式拾取。只有目标圆心实际进入消除矩形且该次拾取成功才删除。圆环外、遮挡和漏检物品保留在仿真真值中，仍参与全程避碰。若 SDK 未收到这些物品，仿真执行前仍要用完整场景试跑，记录安全拒绝或拾取冲突。单次计划里只清除获准拾取的批次 ID。
5. **清完本批后在当前位置原地再看。** 用新位姿更新目标连线和视野。优先复查有未确认线索的方向，再补有观测价值的盲区。有效空帧只确认这次视野内未检测到物品。剩余线索仍在时按下一轮处理，暂无安全动作时停稳并报告剩余物品和原因。

所有阶段沿用现有运动规则。转向在原地执行，平移为前向直行。实际平移大于 5 cm，实际转向大于 1°。碰撞和越界使用连续扫掠检查。普通场地 fence 生效时，车身安全轮廓和消除器均受其约束。

## 仿真接口和回放

- **上层接口。** 复用现有 `Scene` 与 `PoseController`。上层可读取当前实测位姿、下发纯转向或前向直行动作、停稳后取帧、执行指定拾取停靠，并得到成功、受阻及原因。安全预检在场景副本上执行，拒绝时保留当前实测位姿和目标状态。支持无界面运行，便于之后替换选向规则并跑批量对比。
- **感知输入。** 观测帧含帧号、采集位姿、视野、目标检测及粗测或精测标记。远处坐标可加可重复的误差，近距精测在视野内且无遮挡时提供坐标。支持固定遮挡、偶尔漏检和空帧用例。真值坐标用于仿真和事后评估。上层只读公开观测结果。
- **HTML 动画。** 显示车身、安全外扩、消除矩形、场地边界、发现扇区、清理圆环及生效中的 `auto_fence`。显示已观测目标的动态连线，区分粗测、精测、当批目标和已拾取目标。标明当前动作及选向理由，支持暂停和逐步查看。用一份仿真轨迹驱动回放。
- **可复现数据。** 随回放导出场景配置、随机种子、初始真值、观测帧、候选和选中朝向、动作及实际轨迹、每轮 SDK 输入和输出、拾取结果、剩余目标和停止原因。

## 验收场景

| 用例 | 预期结果 |
| --- | --- |
| 左右各一簇，目标数量不同 | 先选角度能覆盖更多连线的方向。接近并停稳后按实测位姿重算圆环，只将圆环内的精测目标分入本批。清完后从新车位再决定方向。 |
| 同方向上有近、中、远多个目标 | 最近目标渐近到短半径附近。停稳后验证圆环的内外边界，圆环外的物品继续保留。 |
| 最近目标偏离前进中心线 | 例如起点为 `(0.8, 2.1, 0)`，目标为 `(2.1, 2.4)`，短半径为 0.75 m。沿车头前进约 0.61 m 可到短半径。按实际径向距离验证停车。另设横向偏差大于短半径加容差的用例，验证无法到达时停止推进。 |
| 目标最初被遮挡，清完前一簇后可见 | 下一轮原地观测发现剩余物品并更新连线。此前的漏检或空帧保留未拾取状态。 |
| 覆盖最多的朝向转不过去，或直行会碰撞 | 安全检查拒绝该动作。上层可尝试其他候选，全部受阻时停车并记录原因。 |
| 局部路线要求车中心超出 `auto_fence` | 拒绝该路线。验证可行路线的全部车中心轨迹都在本次规划的固定圆内。 |
| 只剩粗测或当前没有安全可执行动作 | 保留剩余线索和结束原因，回放可区分已全清和有剩余。 |

请先交付可编辑的场景配置、可重复的离屏运行入口、至少一个贯穿完整流程的 HTML 回放和对应 JSON。后续策略对比使用同一批场景和种子，先看是否安全全清，再比较观测次数、累计转角、渐近和拾取路程、拾取停靠次数及完成时间。可以先对比「当前覆盖的连线数」和「渐近停稳后预计进入圆环的目标数」两种选向规则。
