# v0.2.0 静态路径长度优化版

封版日期：2026-11-08。Git 标签：`v0.2.0`。规划器包版本：`route-plan-planner 0.2.0`；仿真包沿用 `route-plan-sim 0.1.0`。

## 功能范围

本版本处理启动时全部目标已被完整准确观测、运行期间保持静态的消除任务。必须全部清除，并遵守禁止倒车、转向与前进分离、连续碰撞检测及地图边界约束。

- 保留 `--method feasibility` 可行性 baseline。
- 新增 `--method length`，在可行初解上优化车身中心的总平移路程。
- 通过路径捷径、局部消除顺序调整、接近位姿重建及有限宽度搜索改善路线。
- 预算耗尽或改进方案验证失败时保留原可行方案，不要求全局最优。
- 提供同场景、同初解 A/B 对比，保存完整运行记录并支持独立回放。

## 验证基线

| 检查 | 封版依据 |
| --- | --- |
| 仿真测试 | 49 项通过 |
| 规划器测试 | 21 项通过 |
| A/B 测试范围 | 默认前方点群、四周包围、随机种子 0–99，共 102 个场景 |
| A/B 完整清除且无碰撞 | 两组均为 102/102 |
| 路线变化 | 101 组更短、1 组不变、0 组变长 |
| 总路程 | A 为 4632.97 米，B 为 3962.25 米，减少 14.5% |
| 本机平均规划与验证耗时 | A 为 0.32 秒，B 为 3.24 秒 |

每场搜索预算 3 秒，初解耗时计入 B 的预算，最终安全回放可增加墙钟耗时。上述数字为固定集合的一次实测，不保证任意布局可解、重新搜索产生相同路线或耗时。

验证摘要：[长度优化 A/B 记录](../../planner/benchmarks/length-ab-v1.json)。测试方法及能力边界：[路径长度优化说明](../path-length-optimization.md)。

## 复现

从仓库根目录执行：

```bash
uv sync --project planner --locked
uv run --project planner --locked route-plan --version
uv run --project planner --locked route-plan solve --method length --scenario random --seed 7 --timeout 3 --show
uv run --project planner --locked route-plan compare --seeds 0:100 --timeout 3 --output sim/output/length-ab
uv run --project sim --locked python -m unittest discover -s sim/tests -v
uv run --project planner --locked python -m unittest discover -s planner/tests -v
```

Conda 环境的安装与启动方式见 [planner/README.md](../../planner/README.md)。完整逐例记录、截图和动画继续放在被忽略的 `sim/output/`，不纳入版本提交。
